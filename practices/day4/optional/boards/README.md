# Optionale reale Boards

Dieses Verzeichnis ist für board-spezifische Overlays und Konfigurationen vorgesehen.
Die Übungen des Tages benötigen sie nicht: Referenz- und Abnahmepfad bleiben
vollständig auf `native_sim`.

Für `nrf52-dongle` oder `esp32-c5-devkitc-1` sollten erst dann Dateien ergänzt
werden, wenn das konkrete Board lokal verfügbar ist und die Zuordnung von LED,
Taster, Bus und Netzwerkinterface auf der verwendeten Zephyr-Version geprüft wurde.
Ungeprüfte Overlays sind bewusst nicht Bestandteil der Übungslösung.
