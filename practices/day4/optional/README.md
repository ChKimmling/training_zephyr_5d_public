# Optionale Transfers

Erst nach bestandener `native_sim`-Abnahme bearbeiten. Vorgesehene Ziele sind
`nrf52840dongle/nrf52840` und das ESP32-C5-DevKitC-1. Die konkrete Sensorverdrahtung ist
kursabhängig; deshalb werden keine ungeprüften Hardwareoverlays als Pflichtmaterial geliefert.

`transport_ble/transport_ble.c` zeigt ausschließlich die gemeinsame Snapshot-Grenze. Das
Modul ist standardmäßig nicht im Build und verändert weder Probe noch Fachlogik.
